Colour-Based Product Sorting Using Python

Project Overview

This project aims to detect product colours using a camera and Python-based image processing techniques. Based on the detected colour, products can be classified and directed to their corresponding designated areas. The system is designed to improve product organization and reduce manual sorting effort.

Objectives

- Detect product colours using a camera.
- Process captured images using Python.
- Classify products according to their colours.
- Assign products to their respective sorting areas.
- Explore automation in product sorting.

Technologies Used

- Python
- OpenCV
- Computer Vision
- Image Processing

Working Principle

1. The camera captures an image of the product.
2. Python processes the captured image.
3. The system identifies the product's colour.
4. The product is classified according to its detected colour.
5. The product is assigned to its corresponding designated area.

Applications

- Industrial product sorting
- Warehouse management
- Manufacturing automation
- Quality control systems

Future Enhancements

- Integrate a conveyor belt for moving products.
- Use a robotic arm to physically place products.
- Improve colour detection under different lighting conditions.
- Support multiple product colours and categories.
